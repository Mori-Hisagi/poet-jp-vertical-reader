# poet.jp 縦書きリーダー v1.0.0

poet.jp の作品ページ（`https://poet.jp/photo/数字/`）で、画像を元の表示幅で読み、**画像の下の詩だけを縦書き**にするブラウザー拡張機能です。

## v1.0.0 の仕様

- 画像を小さなサムネイルへ縮める「一画面内の高さ制限」を撤廃しました。
- 元ページでの画像の表示幅を取得して再現し、画面より幅が大きい場合のみ縮小します。
- 画像は全体を縦にスクロールして閲覧できます。画像の下に独立した縦書き読書エリアがあります。
- 画像の有無にかかわらず、読書エリアは v0.3.0 と同じく上部ツールバー・下部操作欄などを除いた画面の残りの高さを使います。画像がある場合も、詩の縦幅を縮めません。
- 画像の向き・縦横比を変更せず、クリック拡大にも引き続き対応しています。

## 主な機能

- 作品画像を元ページに近い表示幅で表示（複数画像は縦に並べる）。
- 詩の本文を縦書きにして右から左へ読み進める。
- 文字サイズ変更、ページ送りと進捗スライダー、タイトル・投稿者表示。
- 画像のクリック拡大。
- 本文抽出ができない場合の手動入力欄。
- 画像のある作品では、詩にカーソルを重ねてホイール操作しても画面全体が上下にスクロールします。画像へ戻るときにカーソルを移動する必要がありません。
- 画像付き作品の詩の横移動は、下部のボタン・スライダー、Shift+ホイール、またはトラックパッドの横方向操作で行えます。画像のない作品は従来どおりホイールで列送りできます。

## Chrome / Edge

1. ZIPを解凍します。
2. `chrome://extensions` または `edge://extensions` を開き、開発者モードを有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」から展開したフォルダーを選びます。
4. poet.jp の作品ページを再読み込みしてください。

**以前の試作版を読み込んでいる場合**、同じ拡張機能フォルダーの中身を差し替えて再読み込みするか、旧版を無効化・削除してから読み込んでください（二重表示防止）。

## Firefox

1. ZIPを解凍します。
2. `about:debugging` →「この Firefox」→「一時的なアドオンを読み込む」を開きます。
3. フォルダー内の `manifest.json` を選択します。
4. poet.jp の作品ページを再読み込みしてください。

通常のFirefoxの一時読み込みは、Firefoxを再起動すると解除されます。

## 注意点

- 元ページのHTML構造に基づいて画像と本文を抽出します。サイト側の構造変更や画像の配置によって認識できない場合があります。
- 画像の大きさは元ページで表示されているCSSピクセル幅を再現します。小画面では画面幅に合わせて縮小します。
- 本文の途中に埋め込まれた画像も、原則として上の画像エリアにまとめます。
- 作品内容を外部サーバーへ送信しません。設定として保存するのは文字サイズのみです。
